## 🔧 具体要求与约束 (Requirements & Constraints)

### 技术栈约束
- **语言**: Python 3.11+ (strict typing with mypy)
- **框架**: FastAPI (异步处理模式)
- **架构模式**: 分层架构 + 服务模式 + 异步处理
- **性能要求**: API响应时间 < 30秒，支持并发处理，文件大小限制100MB

### 功能要求

#### 1. 文件上传与存储
- 支持multipart/form-data文件上传
- 支持视频格式：MP4, MOV, AVI, WebM
- 文件验证：格式检查、大小限制、恶意文件检测
- 上传到腾讯云COS存储，获得可访问URL

#### 2. 视频转音频处理 (核心功能)
- **必须使用FFmpeg实现视频到音频的格式转换**
- 支持输入格式：MP4, MOV, AVI, WebM
- 输出格式：MP3/WAV（腾讯云ASR支持的格式）
- 转换参数：采样率16kHz，单声道，比特率128k
- 错误处理：转换失败、超时处理、临时文件清理

#### 3. 腾讯云ASR集成
- 使用腾讯云语音识别SDK（录音文件识别功能）
- 支持MP3/WAV音频文件识别
- 返回文本转换结果和置信度
- 处理ASR服务限流和错误响应

#### 4. 信任之钩分析
- 基于关键词规则匹配引擎
- 识别钩子类型：建立权威、制造冲突、展示稀缺、引发好奇
- 提取匹配的关键词和置信度
- 生成结构化的分析结果

#### 5. 数据库操作
- 创建AnalysisCard记录
- 支持事务回滚机制
- 关联MediaFile记录
- 存储完整的分析结果JSON

### 质量标准
- **类型安全**: 所有函数参数和返回值必须有完整的类型注解
- **错误处理**: 覆盖网络异常、文件格式错误、转换失败、服务限流等场景
- **日志记录**: 关键操作节点的详细日志，支持错误追踪
- **性能监控**: API响应时间、转换耗时、ASR调用时间的监控
- **测试覆盖率**: 单元测试覆盖率 ≥ 80%，集成测试覆盖完整流程

### 类型安全要求 (🛡️ Type Safety)
- **类型优先设计**: 先定义完整的Pydantic模型，再实现功能
- **接口一致性**: 确保类型定义与实际实现完全匹配

```python
# app/schemas/analyze_schema.py
from pydantic import BaseModel, Field
from typing import Optional, List, Dict, Any, Literal
from datetime import datetime
from enum import Enum

class AnalyzeRequest(BaseModel):
    content_type: Literal["file", "text"]
    file_data: Optional[bytes] = None
    text_content: Optional[str] = None
    analysis_options: Optional[Dict[str, Any]] = None

class AnalysisStatus(str, Enum):
    PENDING = "pending"
    PROCESSING = "processing"
    COMPLETED = "completed"
    FAILED = "failed"

class TrustHook(BaseModel):
    hook_type: Literal["建立权威", "制造冲突", "展示稀缺", "引发好奇"]
    content: str = Field(..., description="钩子内容文本")
    confidence: float = Field(..., ge=0.0, le=1.0, description="置信度")
    matched_keywords: List[str] = Field(default_factory=list)

class AnalysisResult(BaseModel):
    task_id: str
    status: AnalysisStatus
    progress: float = Field(default=0.0, ge=0.0, le=1.0)
    result: Optional[Dict[str, Any]] = None
    error_message: Optional[str] = None
    created_at: datetime
    updated_at: datetime
```

## 🚨 重要注意事项 (Important Notes)

### 技术风险及缓解措施

#### 1. FFmpeg依赖风险
- **风险**: FFmpeg未安装或版本不兼容导致转换失败
- **缓解**: 在代码中检查FFmpeg可用性，提供清晰的安装指导，考虑Docker部署

#### 2. 腾讯云ASR配额限制
- **风险**: API调用超出配额或遇到限流
- **缓解**: 实现指数退避重试机制，监控API使用量，设置合理的错误提示

#### 3. 大文件处理内存溢出
- **风险**: 100MB视频文件处理可能导致内存不足

- **缓解**: 实现WebSocket或轮询机制，提供详细的进度反馈

#### 1. 错误处理模式

```python
# 统一的错误处理装饰器
from functools import wraps
def handle_service_errors(func):
    @wraps(func)
    async def wrapper(*args, **kwargs):
        try:
            return await func(*args, **kwargs)
        except SpecificServiceError as e:
            logger.error(f"Service error in {func.__name__}: {e}")
            raise HTTPException(status_code=422, detail=str(e))
        except Exception as e:
            logger.error(f"Unexpected error in {func.__name__}: {e}")
            raise HTTPException(status_code=500, detail="Internal server error")
    return wrapper
```

```python
# 确保临时文件清理
import contextlib
@contextlib.asynccontextmanager
async def temp_file_manager(suffix: str):
    temp_file = None
    try:
        temp_file = tempfile.NamedTemporaryFile(suffix=suffix, delete=False)
        yield temp_file.name
    finally:
        if temp_file and os.path.exists(temp_file.name):
            os.unlink(temp_file.name)
```

### 常见Bug预防

#### 1. 文件路径处理错误预防
- ❌ **错误做法**: 直接拼接字符串路径 `path + "/" + filename`
- ✅ **正确做法**: 使用 `pathlib.Path` 处理路径 `Path(path) / filename`

#### 2. 异步资源泄露预防
- ❌ **错误做法**: 忘记关闭文件句柄和网络连接
- ✅ **正确做法**: 使用 `async with` 上下文管理器确保资源释放

#### 3. 类型转换错误预防
- ❌ **错误做法**: 假设外部服务返回固定格式 `result['text']`
- ✅ **正确做法**: 使用Pydantic验证和Optional类型 `result.get('text', '')`

#### 4. 数据库事务不一致预防
- ❌ **错误做法**: 在多个操作中间可能失败而不回滚
- ✅ **正确做法**: 使用数据库事务确保操作原子性
