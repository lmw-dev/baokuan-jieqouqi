## 🚨 重要注意事项 (Important Notes)

### 技术风险
- **Logto配置错误**: 确保回调URL、应用ID等配置正确
- **状态同步问题**: 注意前端状态与后端session的一致性
- **路由保护遗漏**: 确保所有需要认证的页面都受到保护

### 最佳实践
- **错误处理**: 为所有认证异常提供用户友好的错误提示
- **性能优化**: 认证状态检查应该是轻量级操作
- **安全考虑**: 敏感信息（如token）的存储和传输要安全

### 常见Bug预防 (基于TOM-109调试经验)

#### 1. 接口依赖错误预防
- ❌ **错误做法**: 假设api-client有`post()`方法
- ✅ **正确做法**: 先搜索 `grep_search "export.*api.*client"` 确认实际的方法名

#### 2. 状态管理类型不一致预防
- ❌ **错误做法**: 直接修改user-store.ts接口
- ✅ **正确做法**: 先查看现有接口，确保向后兼容地扩展

#### 3. 认证流程逻辑错误预防
- ❌ **错误做法**: 假设认证总是成功
- ✅ **正确做法**: 处理所有可能的认证失败场景

#### 4. 数据库字段类型不匹配预防
- ❌ **错误做法**: logtoId设为required字段
- ✅ **正确做法**: 考虑历史用户，设为optional字段
