## 🚨 **重要注意事项** (Important Notes)

### **技术风险与缓解措施**
- **并发编辑冲突**: 实现乐观锁机制，使用版本号防止数据覆盖
- **权限绕过风险**: 每个API端点都必须验证用户权限，不能仅依赖前端验证
- **性能瓶颈**: TOM-216算法调用可能耗时，必须实现异步处理和超时控制

### **常见Bug预防**
#### 1. 接口依赖错误预防
- ❌ **错误做法**: 假设方法名 `this.scriptGenerator.generate()`
- ✅ **正确做法**: 先搜索接口 `grep_search "class ScriptGenerator"` 确认实际方法名

#### 2. 权限验证漏洞预防  
- ❌ **错误做法**: 只在路由层验证用户登录状态
- ✅ **正确做法**: 每个数据库操作都验证资源所有权

#### 3. 数据库事务错误预防
- ❌ **错误做法**: 忽略多表操作的事务一致性
- ✅ **正确做法**: 脚本创建涉及多表时使用数据库事务
