### 🎯 **执行目标**
```
在FastAPI服务中构建AI分析引擎，实现"三段式爆款公式"解构功能。包括：
1. 创建可复用的LLM客户端模块
2. 实现"信任之钩"分析模块（钩子类型、证言、权威信号）
3. 实现"共情之锚"分析模块（痛点识别、受众分析、情感触发器）
4. 实现"价值图谱"分析模块（价值交付物分析）
5. 提供统一的API接口供前端调用
```

### 📝 **业务背景**
```
"三段式爆款公式"是我们原创的内容分析方法论：
- 信任之钩：通过开场钩子、可信度证言、权威信号建立信任
- 共情之锚：通过痛点识别、受众定位、情感触发建立共情
- 价值图谱：通过价值交付物分析展示核心价值
目标是让内容创作者能够快速理解爆款内容的成功模式
```
