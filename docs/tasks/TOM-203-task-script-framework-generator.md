### 🎯 **执行目标**
```
实现完整的"一键生成脚本框架"功能，包括：
1. 在卡片详情页添加"一键生成脚本框架"按钮
2. 前端调用后端AI服务传递AnalysisCard ID
3. 后端AI服务查询数据库获取卡片数据
4. 集成LLM API生成结构化脚本框架
5. 前端展示生成的脚本框架并提供编辑功能
6. 确保整个流程响应时间在10秒内
```

### 📝 **业务背景**
```
这是产品价值闭环的关键功能，用户通过分析爆款视频后，可以一键生成基于分析结果的脚本框架，快速开始新视频创作。生成的脚本框架应作为"创作脚手架"，提供结构化的创作指导。
```

### 🔧 **技术约束**
```
- 必须在FastAPI后端服务中实现AI生成逻辑
- 必须使用大型语言模型API进行文本生成
- 必须设计精良的Prompt确保生成质量
- 必须支持结构化的Markdown或富文本格式
- 必须提供用户编辑区域和占位符
- API响应时间必须控制在10秒内
- 必须处理LLM API调用的异常情况
```
