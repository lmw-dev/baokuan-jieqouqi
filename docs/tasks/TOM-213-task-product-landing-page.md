### 1. 🎯 核心目标 (Objective)

为"爆款解构器"产品开发一个专业、美观、功能完整的首页，作为用户进入产品的第一触点。该页面需要清晰传达产品价值，提供文件上传和文案输入两种分析入口，并与现有的Logto认证系统无缝集成。

**关键成果**：
- 完成产品首页的UI设计和交互实现
- 实现文件选择和文案输入的基础交互功能
- 集成认证系统，提供流畅的用户体验
- 确保响应式设计，适配各种设备

### 2. 📝 需求与用户故事 (Requirements & User Story)

**作为一名内容创作者**，
我希望能够访问一个直观的产品首页，
以便于我能够快速了解产品价值，并选择合适的方式（上传视频文件或输入文案）来分析爆款内容。

**核心功能需求**：
- **Hero Section**: 清晰的产品价值传递和品牌展示
- **双重入口**: 支持视频文件上传和文案直接输入两种分析方式
- **认证集成**: 与Logto系统集成，支持用户登录/注册
- **价值展示**: 突出产品三大核心功能（智能解构、结构化分析、一键生成）
- **响应式设计**: 在桌面端、平板端、移动端都有良好体验

### 3. 🛠️ 技术规格与约束 (Technical Specs & Constraints)

**技术栈约束**：
- Next.js 15+ (App Router)
- React 18+ with TypeScript
- shadcn/ui + Tailwind CSS
- Logto认证系统（已集成）
- Zustand状态管理

**设计约束**：
- 必须与现有认证系统完美集成
- 页面加载时间 < 2秒
- 支持主流浏览器和设备
- 遵循Material Design或现代UI设计原则

**功能边界**：
- 本任务仅负责前端页面功能
- 文件实际上传功能由TOM-214任务负责
- AI分析后端逻辑由TOM-214任务负责
