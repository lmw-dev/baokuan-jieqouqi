## 🎯 **战略设计方案** (Strategic Design Solutions)

### 1. 分析卡片9个核心字段设计

| 字段名称 | 字段类型 | 展示组件 | 验证规则 | 默认值处理 |
|---------|---------|----------|----------|------------|
| versionTitle | 单行文本 | Input | 必填，1-50字符 | "AI初稿" |
| hookCopy | 多行文本 | Textarea | 可选，最大1000字符 | 来自AI分析 |
| hookTypes | 标签数组 | TagSelector | 可选，最多5个标签 | 来自AI识别 |
| hookNotes | 多行文本 | Textarea | 可选，最大500字符 | 空值 |
| coreIdea | 多行文本 | Textarea | 可选，最大800字符 | 来自AI提取 |
| argumentCase | 多行文本 | Textarea | 可选，最大1000字符 | 来自AI分析 |
| valueDelivery | 标签数组 | TagSelector | 可选，最多8个标签 | 来自AI识别 |
| reusableElements | 多行文本 | Textarea | 可选，最大600字符 | 来自AI提取 |
| valueNotes | 多行文本 | Textarea | 可选，最大500字符 | 空值 |

**布局设计**：
- 采用3个主要区块：钩子分析、核心观点、价值交付
- 每个区块包含2-3个相关字段，逻辑分组展示
- 移动端适配：单列布局，区块垂直排列

### 2. 编辑/保存模式交互流程

**模式状态**：
- `view`: 只读模式，显示格式化内容
- `edit`: 编辑模式，显示表单控件

**交互流程**：
1. **进入页面** → 默认view模式 → 显示"编辑"按钮
2. **点击编辑** → 切换到edit模式 → 显示"保存"和"取消"按钮
3. **编辑过程** → 实时验证 → 标记未保存变更
4. **保存操作** → 提交数据 → 显示成功Toast → 切换回view模式
5. **取消操作** → 确认对话框（如有变更） → 恢复原始数据 → 切换回view模式

**保存流程优化**：
- 自动保存草稿（每30秒或重要变更时）
- 乐观更新UI（先更新界面，后同步服务器）
- 保存失败时提供重试机制

### 3. 权限控制策略

**多层权限验证**：

**1. 路由层权限（Page级别）**：
```typescript
// 在page.tsx中实现
async function checkCardPermission(cardId: string, userId: string) {
  const card = await prisma.analysisCard.findUnique({
    where: { id: cardId },
    include: { source: { select: { ownerId: true } } }
  });
  
  if (!card) throw new Error('卡片不存在');
  if (card.source.ownerId !== userId) throw new Error('无访问权限');
  
  return card;
}
```

**2. API层权限（接口级别）**：
- GET `/api/cards/[cardId]`: 验证用户是否为卡片创建者
- PUT `/api/cards/[cardId]`: 验证用户是否为卡片创建者
- 返回403状态码当权限不足

**3. 组件层权限（UI级别）**：
- 根据权限状态显示/隐藏编辑按钮
- 只读模式下禁用所有表单控件

**安全策略**：
- 使用Logto会话验证用户身份
- 前后端双重权限验证
- 敏感操作添加二次确认

### 4. 表单验证规则和错误处理

**验证层级**：

**1. 字段级实时验证**：
```typescript
const validationSchema = z.object({

  hookCopy: z.string()
    .max(1000, "钩子文案不能超过1000个字符")
    .optional(),
  hookTypes: z.array(z.string())
    .max(5, "钩子类型最多选择5个")
    .optional(),
  // ... 其他字段验证规则
});
```

**2. 表单级提交验证**：
- 必填字段完整性检查
- 字符长度限制验证

**错误处理策略**：

| 错误类型 | 处理方式 | 用户反馈 | 恢复机制 |

| 服务器错误 | 错误日志 | 友好提示 | 联系支持 |

**用户友好的错误提示**：
