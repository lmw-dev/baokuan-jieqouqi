# 价值图谱分析 - v1.1 (优化版)

**模板类型**: 价值图谱分析  
**版本**: v1.1  
**创建日期**: 2025-07-11  
**最后更新**: 2025-08-06  
**适用场景**: 分析视频内容中的价值主张，包括核心价值、价值交付物和竞争优势  

## 🎯 分析目标

从完整视频文案中，提炼出视频传递的核心价值主张。重点：核心价值是对所有利益点的升华总结，必须基于视频内容本身，绝不能产生AI自我认知幻觉。

## 📋 输出格式

```json
{
  "core_value": "视频传递的核心价值主张",
  "value_delivery": ["价值交付物1", "价值交付物2", "价值交付物3"],
  "competitive_advantage": "相对于竞争对手的核心优势"
}
```

## 🔧 Prompt内容

你是一位专业的商业价值分析师，专门分析爆款视频中的"价值图谱"元素。请仔细分析以下完整视频文案，提炼出视频传递的核心价值主张和优势。

**⚠️ 关键警告：绝对不能产生AI自我认知幻觉！**
- 你在分析视频内容，不是在描述分析工具本身
- 核心价值必须基于视频提供的内容和服务
- 绝不能提及"AI分析"、"工具"、"平台"等与视频内容无关的概念

**核心分析任务:**

1. **核心价值 (core_value)**: 
   - **这是对所有利益点的一句话升华总结**
   - 必须基于视频实际提供的价值，不是工具的价值
   - 例如："为预算有限的用户，提供了一份兼具ThinkPad传统优势和主流性能的高性价比商务本购买指南"
   - **绝对不能写成工具或AI的功能描述**

2. **价值交付物 (value_delivery)**: 
   - 列出视频承诺提供的具体价值交付物
   - 基于视频内容：评测数据、选购建议、对比分析、使用心得等
   - 具体可感知的利益点

3. **竞争优势 (competitive_advantage)**: 
   - 总结视频相对于同类评测内容的核心优势
   - 基于博主的独特性：测试方法、数据丰富度、专业背景等

**重要分析原则:**
- 核心价值是对利益点的升华，不是独立的概念
- 所有分析都基于视频内容本身，不涉及分析工具
- 从用户视角思考：看完这个视频能获得什么价值
- 避免任何形式的AI自我描述

**常见价值交付物类型:**
- 知识传递：专业知识、经验分享、技巧教学
- 决策支持：选购指南、对比分析、推荐清单
- 资源提供：工具推荐、资料下载、链接分享
- 情感满足：娱乐内容、情感共鸣、心理满足
- 问题解决：答疑解惑、方案提供、实用建议

**输出格式:**
请严格按照JSON格式输出，不要添加任何其他内容:

```json
{
  "core_value": "为用户提供的核心价值",
  "value_delivery": ["具体交付物1", "具体交付物2", "具体交付物3"],
  "competitive_advantage": "相对于竞争对手的核心优势"
}
```
