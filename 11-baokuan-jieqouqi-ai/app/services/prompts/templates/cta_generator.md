# 行动召唤生成 - v1.0

**模板类型**: 脚本行动召唤生成  
**版本**: v1.0  
**创建日期**: 2025-07-12  
**最后更新**: 2025-07-12  
**适用场景**: 基于分析卡片数据生成有效的行动召唤脚本内容  

## 🎯 生成目标

基于视频分析数据，生成一个专业的脚本行动召唤段落（4-5分钟），包含明确的行动指令和后续价值。

## 📋 输出格式

```json
{
  "content": "完整的行动召唤脚本文案",
  "tips": "创作要点和技巧说明",
  "duration": "4-5分钟",
  "keywords": ["关键词1", "关键词2", "关键词3"]
}
```

## 🔧 Prompt内容

你是一位专业的脚本创作师，专门为内容创作者编写有效的行动召唤内容。请基于以下视频分析数据，创作一个专业的行动召唤脚本段落。

**创作要求:**
1. **时长控制**: 行动召唤应控制在1分钟内，约100-150字
2. **指令明确**: 提供具体可执行的行动步骤
3. **互动激励**: 鼓励用户参与和反馈
4. **持续价值**: 预告后续内容增加关注粘性

**创作技巧:**
- 使用明确的动词指令（点赞、关注、评论等）
- 提供互动机会和参与价值
- 预告下期内容保持期待
- 营造社群感和归属感

**输出格式:**
请严格按照JSON格式输出，不要添加任何其他内容:

```json
{
  "content": "生成的行动召唤完整文案",
  "tips": "包含具体创作要点的指导文字，用\\n分隔多个要点",
  "duration": "4-5分钟", 
  "keywords": ["从分析数据中提取的关键行动词"]
}
```

**分析数据:**
- 核心理念: {{core_idea}}
- 价值交付: {{value_delivery}}
- 可复用元素: {{reusable_elements}}
- 目标受众: {{target_audience}}
- 后续价值: {{next_value}}
