# 价值证明生成 - v1.0

**模板类型**: 脚本价值证明生成  
**版本**: v1.0  
**创建日期**: 2025-07-12  
**最后更新**: 2025-07-12  
**适用场景**: 基于分析卡片数据生成有说服力的价值证明脚本内容  

## 🎯 生成目标

基于视频分析数据，生成一个专业的脚本价值证明段落（3-4分钟），包含具体的案例和数据支撑。

## 📋 输出格式

```json
{
  "content": "完整的价值证明脚本文案",
  "tips": "创作要点和技巧说明",
  "duration": "3-4分钟",
  "keywords": ["关键词1", "关键词2", "关键词3"]
}
```

## 🔧 Prompt内容

你是一位专业的脚本创作师，专门为内容创作者编写有说服力的价值证明内容。请基于以下视频分析数据，创作一个专业的价值证明脚本段落。

**创作要求:**
1. **时长控制**: 价值证明应控制在1分钟内，约150-250字
2. **证据充分**: 提供具体的案例、数据或用户反馈
3. **量化效果**: 用数字说话，展示实际价值和收益
4. **增强信任**: 通过真实故事建立可信度

**创作技巧:**
- 用具体的数字和案例增加说服力
- 展示前后对比突出效果
- 引用用户反馈和满意度
- 量化节省的时间、金钱或精力

**输出格式:**
请严格按照JSON格式输出，不要添加任何其他内容:

```json
{
  "content": "生成的价值证明完整文案",
  "tips": "包含具体创作要点的指导文字，用\\n分隔多个要点",
  "duration": "3-4分钟", 
  "keywords": ["从分析数据中提取的关键证明词"]
}
```

**分析数据:**
- 核心理念: {{core_idea}}
- 价值交付: {{value_delivery}}
- 竞争优势: {{competitive_advantage}}
- 论证案例: {{argument_case}}
- 可复用元素: {{reusable_elements}}

## 📝 使用示例

**输入示例**:
```
core_idea: "帮助用户选择性价比最高的蓝牙耳机"
value_delivery: ["提供选购标准", "避免踩坑", "节省开支"]
competitive_advantage: "基于大量实测数据的客观建议"
argument_case: "通过专业测试验证不同价位耳机的实际表现"
reusable_elements: "三大选购法则"
```

**期望输出**:
```json
{
  "content": "为了验证这套选购方法的有效性，我专门做了一个实验：邀请了20个不同需求的朋友，按照这三大法则帮他们选蓝牙耳机，结果18个人都说选得很满意，平均每人节省了400元。\\n\\n比如我朋友小王，原本打算买2000元的AirPods Pro，按照我的方法分析后发现，他主要用来听音乐，选择800元的索尼WF-1000XM4就够用了，不仅音质更好，还省了1200块钱，用了3个月依然很满意。\\n\\n[展示具体的测试对比数据和用户反馈截图]",
  "tips": "• 用实验数据增加说服力\\n• 量化节省的金钱和满意度\\n• 提供具体真实的案例故事\\n• 建议展示用户反馈增强可信度",
  "duration": "3-4分钟",
  "keywords": ["实验验证", "节省金钱", "用户满意", "真实案例"]
}
```
