# 痛点共鸣生成 - v1.0

**模板类型**: 脚本痛点共鸣生成  
**版本**: v1.0  
**创建日期**: 2025-07-12  
**最后更新**: 2025-07-12  
**适用场景**: 基于分析卡片数据生成引起用户共鸣的痛点描述脚本内容  

## 🎯 生成目标

基于视频分析数据，生成一个专业的脚本痛点共鸣段落（15-45秒），包含具体的文案内容和创作要点。

## 📋 输出格式

```json
{
  "content": "完整的痛点共鸣脚本文案",
  "tips": "创作要点和技巧说明",
  "duration": "15-45秒",
  "keywords": ["关键词1", "关键词2", "关键词3"]
}
```

## 🔧 Prompt内容

你是一位专业的脚本创作师，专门为内容创作者编写引起共鸣的痛点描述。请基于以下视频分析数据，创作一个专业的痛点共鸣脚本段落。

**创作要求:**
1. **时长控制**: 痛点共鸣应控制在30秒内，约60-100字
2. **情感连接**: 深入挖掘目标用户的真实痛点和困扰
3. **场景描述**: 用具体场景让用户产生"这说的就是我"的感觉
4. **共情引导**: 通过理解和同情建立情感连接

**创作技巧:**
- 使用疑问句增加互动感和代入感
- 列举具体而真实的用户困扰
- 表达理解和同情，建立信任
- 为后续解决方案做铺垫

**输出格式:**
请严格按照JSON格式输出，不要添加任何其他内容:

```json
{
  "content": "生成的痛点共鸣完整文案",
  "tips": "包含具体创作要点的指导文字，用\\n分隔多个要点",
  "duration": "15-45秒", 
  "keywords": ["从分析数据中提取的关键痛点词"]
}
```

**分析数据:**
- 核心理念: {{core_idea}}
- 论证案例: {{argument_case}}
- 目标用户痛点: {{pain_point}}
- 目标受众: {{target_audience}}
- 情感触发点: {{emotional_triggers}}

## 📝 使用示例

**输入示例**:
```
core_idea: "帮助用户选择性价比最高的蓝牙耳机"
argument_case: "大部分用户购买蓝牙耳机时容易被品牌和价格误导"
pain_point: "面对众多蓝牙耳机型号不知道如何选择"
target_audience: "想要购买蓝牙耳机的普通消费者"
emotional_triggers: ["选择困难", "害怕买错", "担心性价比"]
```

**期望输出**:
```json
{
  "content": "你是不是也有这样的困扰：想买个蓝牙耳机，面对几百个品牌几千个型号就头疼？看网上评测说这个好，到手发现不适合自己；买便宜的担心音质差，买贵的又怕花冤枉钱？别担心，这些纠结我都经历过，今天就来帮你彻底解决选择难题。",
  "tips": "• 用疑问句让用户产生代入感\\n• 列举具体的选择困扰场景\\n• 表达理解和同情建立信任\\n• 承诺提供解决方案",
  "duration": "15-45秒",
  "keywords": ["选择困扰", "性价比担忧", "购买纠结", "解决方案"]
}
```
