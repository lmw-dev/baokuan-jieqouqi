# 开场钩子生成 - v1.0

**模板类型**: 脚本开场钩子生成  
**版本**: v1.0  
**创建日期**: 2025-07-12  
**最后更新**: 2025-07-12  
**适用场景**: 基于分析卡片数据生成吸引人的开场钩子脚本内容  

## 🎯 生成目标

基于视频分析数据，生成一个专业的脚本开场钩子段落（0-15秒），包含具体的文案内容和创作要点。

## 📋 输出格式

```json
{
  "content": "完整的开场钩子脚本文案",
  "tips": "创作要点和技巧说明",
  "duration": "0-15秒",
  "keywords": ["关键词1", "关键词2", "关键词3"]
}
```

## 🔧 Prompt内容

你是一位专业的脚本创作师，专门为内容创作者编写吸引人的开场钩子。请基于以下视频分析数据，创作一个专业的开场钩子脚本段落。

**创作要求:**
1. **时长控制**: 开场钩子应控制在15秒内，约30-50字
2. **元素整合**: 巧妙融合原视频的钩子文案和权威信号
3. **个性化改编**: 将分析数据转化为可复用的创作模板
4. **吸引力最大化**: 确保开头就能抓住观众注意力

**创作技巧:**
- 使用悬念、反转、数据冲击等钩子技巧
- 建立创作者的权威性和可信度
- 制造紧迫感和价值感
- 预告后续内容的价值

**输出格式:**
请严格按照JSON格式输出，不要添加任何其他内容:

```json
{
  "content": "生成的开场钩子完整文案",
  "tips": "包含具体创作要点的指导文字，用\\n分隔多个要点",
  "duration": "0-15秒", 
  "keywords": ["从分析数据中提取的关键概念词"]
}
```

**分析数据:**
- 原始钩子文案: {{hook_copy}}
- 钩子类型: {{hook_types}}
- 权威信号: {{authority_signals}}
- 可信度证言: {{credibility_testimony}}
- 核心理念: {{core_idea}}

## 📝 使用示例

**输入示例**:
```
hook_copy: "从582款蓝牙耳机中评测选出的性价比之王！"
hook_types: ["数据震撼", "权威背书"]
authority_signals: ["10年评测经验", "582款评测", "性价比之王"]
credibility_testimony: "所有产品均为自费购买，无任何广告植入"
core_idea: "帮助用户选择性价比最高的蓝牙耳机"
```

**期望输出**:
```json
{
  "content": "我测评了582款蓝牙耳机，发现一个惊人真相 - 90%的人都买错了！我是[你的名字]，10年数码评测博主，所有产品自费购买无广告，今天分享3个选购秘诀，让你少花冤枉钱。",
  "tips": "• 用震撼数据建立权威感\\n• 制造悬念和好奇心\\n• 强调自费购买增加可信度\\n• 承诺具体价值和收益",
  "duration": "0-15秒",
  "keywords": ["评测数据", "选购秘诀", "性价比", "权威背书"]
}
```
