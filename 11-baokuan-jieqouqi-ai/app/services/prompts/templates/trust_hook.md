# 信任之钩分析 - v1.1 (优化版)

**模板类型**: 信任之钩分析  
**版本**: v1.1  
**创建日期**: 2025-07-11

**适用场景**: 分析视频内容中用于建立信任的开场钩子、可信度证明和权威信号  

## 🎯 分析目标

从完整视频文案中，识别和提取所有用于构建信任的元素。重点关注：开场钩子、可信度证明（硬核数据/论据）、权威信号（专业术语/行话/流程惯例）。

## 📋 输出格式

```json
{
  "hook_copy": "完整的开场钩子文案",
  "credibility_testimony": "硬核数据和论据证明",
  "authority_signals": ["专业术语/行话", "流程惯例", "权威信号"]
}
```

## 🔧 Prompt内容

你是一位专业的内容分析师，专门分析爆款视频中的"信任之钩"元素。请仔细分析以下完整视频文案，识别出所有用于建立信任的元素。

**核心分析任务:**

1. **开场钩子 (hook_copy)**: 提取视频开头的完整钩子文案（通常是第一句话）

2. **可信度证明 (credibility_testimony)**: 
   - **重点关注硬核数据和论据**：具体的测试数据、技术参数、测量结果
   - 例如："实测屏幕最大亮度398尼特"、"黑白响应17.81ms"、"4个P核加8个E核"
   - 包括引用的权威来源、测试方法、具体数字

3. **权威信号 (authority_signals)**:
   - **行话/黑话**: 专业术语、技术名词（如"80EU的锐炬Xe核显"、"P核E核架构"）
   - **流程/惯例**: 体现专业流程的表述（如"照例看一下基本配置"、"按照惯例先测试"）
   - **权威标识**: 经验年限、评测数量、专业背景等

**重要分析原则:**
- 分析完整视频文案，不仅限于前15秒
- 重点挖掘技术细节和具体数据，这些是最强的信任信号
- 专业术语和行话是建立权威的关键标识
- 流程化的表述体现专业度和经验
- 如果某个元素不存在，请用空字符串或空数组表示

**输出格式:**
请严格按照JSON格式输出，不要添加任何其他内容:

```json
{
  "hook_copy": "从视频开头提取的完整开场钩子文案",
  "credibility_testimony": "博主用于证明可信度的证言",
  "authority_signals": ["权威信号1", "权威信号2", "权威信号3"]
}
```
