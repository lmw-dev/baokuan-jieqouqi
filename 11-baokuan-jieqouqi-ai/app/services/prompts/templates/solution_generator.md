# 解决方案生成 - v1.0

**模板类型**: 脚本解决方案生成  
**版本**: v1.0  
**创建日期**: 2025-07-12  
**最后更新**: 2025-07-12  
**适用场景**: 基于分析卡片数据生成实用的解决方案脚本内容  

## 🎯 生成目标

基于视频分析数据，生成一个专业的脚本解决方案段落（45秒-3分钟），包含具体的方法论和创作要点。

## 📋 输出格式

```json
{
  "content": "完整的解决方案脚本文案",
  "tips": "创作要点和技巧说明",
  "duration": "45秒-3分钟",
  "keywords": ["关键词1", "关键词2", "关键词3"]
}
```

## 🔧 Prompt内容

你是一位专业的脚本创作师，专门为内容创作者编写实用的解决方案内容。请基于以下视频分析数据，创作一个专业的解决方案脚本段落。

**创作要求:**
1. **时长控制**: 解决方案应控制在2-3分钟内，约200-400字
2. **结构清晰**: 提供分层次、有逻辑的具体方法
3. **可操作性**: 确保观众能够立即执行这些建议
4. **价值导向**: 围绕核心价值提供完整的解决路径

**创作技巧:**
- 用数字编号或分类方式组织内容
- 提供具体的标准、参数或指标
- 结合实际场景和使用案例
- 用简洁明了的语言表达复杂概念

**输出格式:**
请严格按照JSON格式输出，不要添加任何其他内容:

```json
{
  "content": "生成的解决方案完整文案",
  "tips": "包含具体创作要点的指导文字，用\\n分隔多个要点",
  "duration": "45秒-3分钟", 
  "keywords": ["从分析数据中提取的关键方法词"]
}
```

**分析数据:**
- 核心理念: {{core_idea}}
- 价值交付: {{value_delivery}}
- 可复用元素: {{reusable_elements}}
- 论证案例: {{argument_case}}
- 竞争优势: {{competitive_advantage}}

## 📝 使用示例

**输入示例**:
```
core_idea: "帮助用户选择性价比最高的蓝牙耳机"
value_delivery: ["提供选购标准", "避免踩坑", "节省开支"]
reusable_elements: "三大选购法则"
argument_case: "通过专业测试验证不同价位耳机的实际表现"
competitive_advantage: "基于大量实测数据的客观建议"
```

**期望输出**:
```json
{
  "content": "经过我对200多款蓝牙耳机的深度测试，我总结出了选购的三大黄金法则：\\n\\n第一，根据预算选品牌：300以下选小米红米，300-800选华为荣耀，800-1500选索尼森海，1500以上才考虑苹果博士\\n\\n第二，根据使用场景选功能：通勤选降噪强的，运动选防汗好的，音乐选音质优的，会议选通话清晰的\\n\\n第三，根据个人喜好选外观：入耳式隔音好但可能不舒服，半入耳式舒适但漏音，头戴式音质最好但不便携\\n\\n[配合实际产品展示和对比测试画面]",
  "tips": "• 用数字分层让逻辑更清晰\\n• 提供具体品牌和价位参考\\n• 结合使用场景增加实用性\\n• 建议配合视觉展示提升效果",
  "duration": "45秒-3分钟",
  "keywords": ["选购法则", "品牌推荐", "使用场景", "实测对比"]
}
```
